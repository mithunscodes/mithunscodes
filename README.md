## 🚀 Featured Projects

### [SecureNet AI](https://github.com/mithunscodes/securenet-ai)
**Real-Time Network Intrusion Detection System**  
Built a full-stack cybersecurity monitoring platform using a CNN-LSTM hybrid neural network to detect 6 types of network attacks in real-time with 97.41% accuracy.

🛠️ **Tech:** Python • Flask • TensorFlow • React • WebSockets • SQLite  
✨ **Highlights:**
- Trained on 2.83M network flows from CIC-IDS-2017 dataset
- Real-time dashboard with live attack visualization
- Automated SMTP alerting for critical threats
- Processes 78 network flow features per prediction
